
# 🏔️ Mountify Frontend

Modern web application untuk sistem rekomendasi jalur pendakian gunung berbasis fuzzy logic. Membantu pendaki memilih jalur terbaik sesuai preferensi dan kondisi terkini.

## 🚀 Tech Stack

- **React 19** - Frontend framework
- **React Router** - Client-side routing
- **Tailwind CSS** - Utility-first CSS framework  
- **Chart.js** - Data visualization
- **SweetAlert2** - Beautiful alerts
- **React Toastify** - Notification system
- **Bootstrap Icons** - Icon library

## ✨ Key Features

### 🎯 Smart Recommendation System
- **AI-powered trail recommendations** using fuzzy logic
- **Multi-criteria filtering** (difficulty, safety, cost, etc.)
- **Real-time sorting** by distance, score, and cost
- **Interactive preference settings**

### 🗺️ Exploration & Discovery
- **Comprehensive mountain database**
- **Detailed trail information** with maps and photos
- **Interactive gallery** with user-generated content
- **Weather data integration**

### 👤 User Experience
- **Responsive design** for all devices
- **Intuitive admin dashboard**
- **User authentication** with Google OAuth
- **Personal profile management**

### 📱 Modern Interface
- **Clean, modern UI/UX**
- **Dark/Light theme support**
- **Mobile-first responsive design**
- **Progressive web app features**

## Instalasi & Menjalankan Frontend

### 1. Masuk ke folder frontend:
   ```
   cd frontend
   ```

### 2. Install dependencies utama:
   ```
   npm install
   ```
   Dependencies utama yang akan di-install otomatis:
   - react, react-dom, react-router-dom, react-scripts, react-toastify, recharts, chart.js, sweetalert2, sweetalert2-react-content, bootstrap, dompurify, @tiptap/react, @tiptap/starter-kit, @tiptap/extension-link, web-vitals

   Dev dependencies:
   - tailwindcss, postcss, autoprefixer, cross-env, @babel/preset-env, @babel/preset-react

   Untuk testing (opsional):
   - @testing-library/react, @testing-library/jest-dom, @testing-library/user-event, @testing-library/dom

### 3. Jalankan aplikasi:
   ```
   npm start
   ```
   Aplikasi akan berjalan di [http://localhost:3000](http://localhost:3000)
